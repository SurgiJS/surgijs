`@surgijs/ui/angular` exports a directive per component, `SButtonDirective` for `<s-button>`, with an input for each prop of its props interface. Angular checks template bindings against those inputs, so an unknown `variant` or a value of the wrong type is a compile error, and the directive forwards each input to the element. Generated from the same manifest as the React and Vue typings.
